Bitten Sie den Agenten, mit dem Sie sprechen, als Teamleitung die Arbeit aufzuteilen. Er erstellt benannte Teammitglieder, trägt die Arbeit auf einem gemeinsamen Aufgabenboard ein, wartet auf ihre Ergebnisse und berichtet Ihnen darüber.

## Verwendung

- Formulieren Sie Ihre Bitte in eigenen Worten, zum Beispiel: „Nutze Agententeams, um diese Aufgabe auf zwei Teammitglieder aufzuteilen, warte auf den Abschluss und fasse die Ergebnisse zusammen.“
- Klicken Sie neben dem Titel der Unterhaltung auf **Agententeam**, um **Mitglieder** und **Geteilte Aufgaben** anzuzeigen. Jede Aufgabe zeigt ihren Status, **Besitzer**, Schreibbereiche (**Bereiche schreiben**) und die Aufgaben, von denen sie abhängt, unter **Blockiert von**.
- Klicken Sie auf ein Teammitglied, um dessen Unterhaltung zu öffnen und dort direkt mit ihm zu sprechen.
- Das Panel ist schreibgeschützt. Bitten Sie die Teamleitung, Aufgaben oder Teammitglieder zu ändern.

## Gut zu wissen

- Jedes Teammitglied ist ein eigener Agent mit eigenen Modellanfragen. Ein Team verbraucht daher mehr Tokens als ein einzelner Agent.
- Alle Teammitglieder nutzen dieselben Dateien. Überschneidungen der Schreibbereiche (**Bereiche schreiben**) lösen lediglich eine Warnung aus; zwei Teammitglieder können weiterhin dieselbe Datei bearbeiten.
- Ein Team kann insgesamt höchstens 8 Teammitglieder erstellen, einschließlich derjenigen, deren Start fehlgeschlagen ist, und höchstens 256 Aufgaben vorhalten. Das Löschen einer Aufgabe gibt einen Platz frei.
- Solange das Plugin aktiviert ist, sind die gewöhnlichen Subagentenwerkzeuge deaktiviert und Agenten delegieren über das Team. Workflows können weiterhin Agenten für einen einzelnen Durchlauf starten. Das Deaktivieren des Plugins stellt die Subagentenwerkzeuge wieder her.
- Wenn Sie das Plugin bei geöffneter Unterhaltung aktivieren, laden Sie die Seite neu, um das Panel anzuzeigen.
