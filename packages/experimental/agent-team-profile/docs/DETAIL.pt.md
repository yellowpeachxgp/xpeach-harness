Peça ao agente com quem você conversa, o líder, para dividir o trabalho. Ele cria colegas com nome, coloca o trabalho em um quadro de tarefas compartilhado, aguarda os resultados e os apresenta a você.

## Como usar

- Faça o pedido com suas próprias palavras, por exemplo: «Use equipes de agentes para dividir esta tarefa entre dois colegas, espere que terminem e resuma os resultados».
- Clique em **Equipe de agentes**, ao lado do título da conversa, para ver **Membros** e **Tarefas compartilhadas**. Cada tarefa mostra seu estado, **Proprietário**, escopos de escrita (**Escrever escopos**) e as tarefas das quais depende em **Bloqueado por**.
- Clique em um colega para abrir a conversa dele e falar com ele diretamente.
- O painel é somente leitura. Para alterar tarefas ou colegas, peça ao líder.

## O que você deve saber

- Cada colega é um agente separado com suas próprias solicitações ao modelo, por isso uma equipe consome mais tokens do que um único agente.
- Os colegas compartilham os mesmos arquivos. A sobreposição de escopos de escrita (**Escrever escopos**) apenas exibe um aviso; nada impede que dois colegas editem o mesmo arquivo.
- Uma equipe pode criar no máximo 8 colegas ao todo, incluindo os que não conseguiram iniciar, e manter até 256 tarefas. Excluir uma tarefa libera uma vaga.
- Enquanto o plugin está ativado, as ferramentas comuns de subagentes ficam desativadas e os agentes delegam por meio da equipe. Os fluxos de trabalho ainda podem iniciar agentes de execução única. Desativar o plugin restaura as ferramentas de subagentes.
- Se você ativar o plugin com uma conversa aberta, recarregue a página para ver o painel.
