対話中のエージェント（リーダー）に仕事の分担を依頼してください。リーダーは名前付きのチームメイトを作成し、共有タスクボードに仕事を登録し、結果を待って報告します。

## 使い方

- 普段の言葉で依頼できます。例：「エージェントチームを使ってこのタスクを2名のチームメイトに分担し、完了を待って結果をまとめてください。」
- 会話タイトルの横にある **エージェントチーム** をクリックすると、**メンバー** と **共有タスク** を確認できます。各タスクには状態、**オーナー**、**書き込みスコープ**、依存先のタスクを示す **ブロック元** が表示されます。
- チームメイトをクリックすると、その会話を開いて直接話しかけられます。
- パネルは読み取り専用です。タスクやチームメイトを変更するには、リーダーに依頼してください。

## 注意事項

- 各チームメイトは独立したエージェントとしてモデルへのリクエストを行うため、チームは単独のエージェントより多くのトークンを消費します。
- チームメイトは同じファイルを共有します。**書き込みスコープ** が重なっても警告が表示されるだけで、2名のチームメイトが同じファイルを編集することは防止されません。
- 1つのチームで作成できるチームメイトは、起動に失敗したものも含めて合計8名までです。保持できるタスクは256件までで、タスクを削除すると枠が空きます。
- このプラグインを有効にしている間、通常のサブエージェントツールは無効になり、エージェントはチーム経由で仕事を委任します。ワークフローは引き続き単発のエージェントを起動できます。プラグインを無効にすると、サブエージェントツールが復元されます。
- 会話を開いたままプラグインを有効にした場合は、ページを再読み込みするとパネルが表示されます。
